隱私權政策

一句話總結：這個擴充功能不蒐集你的任何資料，不知道你看了什麼， 也沒有任何伺服器可以接收你的資料。

最後更新：2026 年 9 月 18 日

我們蒐集哪些資料

沒有。一項都沒有。

具體來說，這個擴充功能不蒐集也不傳送：個人識別資訊、健康或財務資訊、身分驗證資訊、 個人通訊內容、位置、瀏覽紀錄、使用者活動（點擊、滑鼠位置、按鍵）、以及網站內容。

擴充功能沒有後端伺服器。開發者無法看到任何使用者的清單、設定或瀏覽行為， 因為這些資料從來沒有離開過你的瀏覽器。

資料存在哪裡

你的警示清單、設定與提醒次數統計，全部存放在瀏覽器本機的 chrome.storage.local，只有這個擴充功能能讀取。

  • 移除擴充功能時，這些資料會一併被瀏覽器刪除。
  • 你可以隨時在設定頁匯出成 JSON 檔備份，或清空全部項目。
  • 資料不會同步到雲端，換一台電腦就是一份新的空清單。

唯一的對外連線

擴充功能只有在一種情況下會連上外部網路：你自己在設定頁填入了「訂閱清單」網址。 這時它會定期下載該網址的 JSON 清單。

  • 下載是單向的——只取得清單內容，不會送出任何關於你的資訊。
  • 沒填訂閱網址，就完全不連外。這是預設狀態。
  • 你填的網址由你選擇，該網站的隱私權政策適用於那次連線。

權限用途

安裝時 Chrome 會列出以下權限，這裡說明每一項的實際用途：

權限用途
storage 在本機儲存你的警示清單與設定。不含任何遠端儲存。
alarms 當你啟用訂閱清單的自動更新時，用來安排定期更新的時間。
facebook.com
threads.net
threads.com		 在這三個網站上比對目前頁面的帳號、顯示警示橫幅與貼文標記。 比對完全在你的瀏覽器內完成。擴充功能讀不到其他網站的任何內容或網址。

擴充功能不使用 tabs 權限，因此看不到你其他分頁的網址； 在 Facebook 與 Threads 以外的頁面，它完全不會執行。

不做的事

  • 不使用任何分析、統計或追蹤服務。
  • 不使用 Cookie，也不寫入任何追蹤識別碼。
  • 不販售、不出租、不轉讓任何資料——因為根本沒有資料可以轉讓。
  • 不會把你的資料用於與核心功能無關的用途。
  • 不會為了判斷債信、貸款資格等目的使用資料。

網站（檢舉頁）的部分

本專案的檢舉頁由 GitHub Pages 託管，同樣不使用 Cookie、不做追蹤、沒有分析工具。 你在檢舉表單填寫的內容，只有在你按下送出、並在 GitHub 上實際建立 Issue 之後才會送出， 屆時那些內容會成為公開的 GitHub Issue。填寫但未送出的內容不會離開你的瀏覽器。

GitHub 對其服務有自己的隱私權政策，請參閱 GitHub Privacy Statement。

政策變更

若日後政策有變動，會更新本頁的「最後更新」日期，並在 GitHub 專案 留下紀錄。所有變更都會反映在公開的原始碼裡——這個擴充功能是開源的， 任何人都可以檢查它實際做了什麼。
